# 1light

Kurzadresse **1light.app** für die kostenlose App „Erstes Licht“ (First Light, Première lueur).

Die Seite leitet sofort zur Web-App weiter: https://humane-weltformel.de/licht/
(mit `mtm_campaign=domains&mtm_source=1light.app` für die eigene Besucherstatistik).

- `1light.app/#heute` oder `1light.app/heute` öffnet direkt „Dein Licht für heute“, ebenso `kalender`, `schreiben`, `schenken`, `fragen`, `erinnern`, `buch`, `info`.
- Läuft über GitHub Pages mit eigener Domain und automatischem HTTPS (nötig, weil .app-Adressen nur verschlüsselt funktionieren).
- DNS bei IONOS: A-Einträge auf GitHub Pages, `www` als CNAME auf `editionresonanz.github.io`.

Herausgeber: Edition Resonanz, Bernd Blasius.
